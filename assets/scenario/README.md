# First-business development scenario

See [the scenario and financial assumptions](../../docs/validation/FIRST_BUSINESS.md#scenario-and-financial-assumptions) for the 12-city roster, four corridor markets, construction alternatives, pricing and sources. The original nine metros retain their supplied coordinates. Tsuruga, Shin-Hakodate-Hokuto and Sapporo use approximate display reference points; polylines are illustrative and cannot price engineering by screen distance.

`business.json` freezes the authored engineering coverage, runtime inputs, outside-option assumptions and alignment sketches. `scenario.json` freezes city identity. `camera.json` retains the East Asia landscape/portrait anchors from the [camera policy](../../data/prototypes/map-region-presets.v1.json) as amended by the [launch framing overrides](../../data/prototypes/launch-map-framing.v1.json), which make Harbin the northern anchor; `regions.json` repeats them as lon/lat. Its `exclude` list holds the metros the frame pans off screen (Dhaka), from the preset's `exclude_metro_ids`; each `regions.json` view carries the same as `exclude` (East Asia: Dhaka; portrait Africa+Arabia: Karachi). The separate camera and Natural Earth display outline do not enter financial distance calculations.

The map's land outline is `assets/terrain/world-land.json`; see [the terrain README](../terrain/README.md#basemap). A display outline does not qualify construction. These scenario estimates support the development loop; production engineering qualification remains required.
