# Unverified proximity review sites

These are 35 review candidates from the older display-geometry audit, not confirmed missing railway links. Each compares fragments within 2 km that remain unconnected by the current source-node assessment. Close parallel tracks, grade-separated crossings, unused fragments and omitted approaches can all produce candidates.

Nearest station names are location hints, not verified junction names. Some markers are more than 20 km from the candidate. The coordinate locates the first compared fragment; separation measures fragment-to-fragment distance, not distance between stations. Older display component memberships are not current playable-catalog connectivity.

The whole-network contracts pass independently. For example, the Kaifeng candidate concerns the old conventional-station area; the playable city now uses Kaifeng North and is connected. These sites are deliberately not snapped together.
